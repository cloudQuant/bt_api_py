SDK 接口为 `parse_client_config`、`parse_service_config`、`load_client_config`、`load_service_config`。结果只可通过解析器构造，内部映射递归冻结，对外返回独立字典及规范化指纹。配置值和未知字段名不进入错误文本。角色、挂载槽、组件端口、配置版本、引用语法、可选只读与必需写能力、账户槽与跨挂载账户一致性、内部组件引用、当前服务自连接、等价 IP bind 冲突均做离线校验。

```text
python -m bt_api_py.service_config_io --role client examples/services/unconfigured-client.yaml
python -m bt_api_py.service_config_io --role service examples/services/account-service.yaml
```

命令成功只返回 `activated: false` 的校验摘要。示例里的身份、政策和服务引用仍需部署时验证；本轮不会解析私密材料、连接账户或启动服务。`{}` 和 `clients: {}` 可保持零能力配置。

Wire v2 使用有界严格 JSON，拒绝重复键、非有限数和非法结构，递归冻结 payload。身份和 scope 始终是待认证的声明；reply 绑定 request 的 correlation、operation、scope 和 owner epoch，可额外绑定可信 peer。事件包含 stream/epoch/sequence。此模块没有导入领域组件或 ZMQ；现有 v1 协议保持独立。
