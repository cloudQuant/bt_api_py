## 1. 设计目标与原则

### 1.1 目标

用一次可审计、可回退、无门禁回归的改动，把 45 个 submodule 从主仓库移除，并把仓库内对它们的引用收敛到零。

### 1.2 设计原则

1. **`.gitmodules` 是唯一真源**：submodule 的"存在性"以 `.gitmodules` 为准。移除时三处同步：`.gitmodules` 条目、git index 的 gitlink（mode `160000`）、工作目录。
2. **动态发现优先，不改主逻辑**：仓库既有代码已用 `glob("bt_api/bt_api_*")`（`scripts/ci/submodule_validation.py`）与 `Path.read_text(.gitmodules)`（`tests/test_repository_baseline.py`）发现 submodule，移除后自动收敛，禁止为"删目录"而改这些逻辑。
3. **先留档后删除**：删除任何东西之前，先把 URL 与 pin SHA 落到本文档附录 A，保证可恢复。
4. **活跃引用清零，历史归档摘除**：活跃代码/配置/文档必须彻底清除；历史归档只摘除引用行，保留其历史证据属性。
5. **成对处理重复脚本**：`scripts/` 与 `scripts/testing/` 存在同名副本，必须成对修改，避免"改了一份漏一份"。
6. **token 甄别**：`gemini`、`buda`、`gmx` 等在别处可能有非交易所含义，逐处人工确认（已确认 `.gitignore` 的 `.gemini/` 是 AI 工具缓存，保留）。

## 2. 引用扫描口径（可复现）

验收与实施均使用同一口径，脚本如下（保存于仓库外执行，不新增仓库文件）：

```python
import pathlib, re, collections

names = [
    l.strip().rsplit("/", 1)[-1]
    for l in pathlib.Path(
        "docs/迭代计划/迭代05-去除最近不准备维护的python子项目/去除清单.md"
    ).read_text().splitlines()
    if l.strip()
]
short = [n[len("bt_api_"):] for n in names]

EXCLUDE_DIRS = {
    ".git", "site", "build", "dist", "node_modules", "__pycache__",
    ".mypy_cache", ".ruff_cache", ".pytest_cache", ".benchmarks",
    ".venv312", ".venv", "tmp_keys", "keys", ".idea",
}
EXCLUDE_EXT = {".pyc", ".pkl", ".so", ".png", ".jpg", ".jpeg", ".gif", ".ico",
               ".woff", ".woff2", ".zip", ".whl", ".tar", ".gz"}

alt = "|".join(re.escape(s) for s in short)
pattern = re.compile(r"(?i)(?:bt_api_(" + alt + r")\b|\b(" + alt + r")\b)")

hits = collections.defaultdict(set)
for p in pathlib.Path(".").rglob("*"):
    if not p.is_file():
        continue
    if set(p.parts) & EXCLUDE_DIRS:
        continue
    if p.suffix.lower() in EXCLUDE_EXT or p.name == ".DS_Store":
        continue
    if p.stat().st_size > 2_000_000:
        continue
    text = p.read_text(encoding="utf-8", errors="ignore")
    found = set((m.group(1) or m.group(2)).lower() for m in pattern.finditer(text))
    if found:
        hits[str(p)] = found

print(f"TOTAL FILES: {len(hits)}")
for f in sorted(hits):
    print(f, ",".join(sorted(hits[f])))
```

**判定**：AC-2 要求「排除本迭代留档文档（`迭代05-…/研发设计文档.md` 附录 A、`去除清单.md`、`实施计划.md`、`验收文档.md`）后，命中文件数为 0」。`bt_api/bt_api_<name>/` 内部文件不计入（随目录整体删除）。

## 3. submodule 移除机制

### 3.1 git 数据模型

一个 submodule 在主仓库中有三处落点：

| 落点 | 内容 | 移除动作 |
|------|------|----------|
| `.gitmodules` | `[submodule "bt_api/x"]` 段（path + url） | 文本删除段 |
| git index | mode `160000` 的 gitlink 对象 | `git rm --cached bt_api/x` |
| 工作目录 | `bt_api/x/`（内含独立 `.git` 文件） | `rm -rf bt_api/x` |
| 本地对象库 | `.git/modules/bt_api/x/` | `rm -rf .git/modules/bt_api/x` |

> `.git/modules/` 是本地 `--separate-git-dir` 存储，不随提交传播。若不清理由它，未来在同 path 执行 `git submodule add` 会因 `.git/modules/bt_api/x` 已存在而报错。

### 3.2 执行顺序

```
1. 读取 .gitmodules 与 git ls-tree HEAD，生成 URL+SHA 留档（附录 A）
2. 逐个：git rm --cached bt_api/<name>
3. 重写 .gitmodules，仅保留 15 个保留段
4. rm -rf bt_api/<name> ×45
5. rm -rf .git/modules/bt_api/<name> ×45
6. 校验：git submodule status --recursive | wc -l == 15
          git ls-files --stage | grep 160000 | wc -l == 15
```

`git rm --cached` 只动 index/`.gitmodules`，不动工作目录，因此必须在删除目录之前执行，避免 `git rm` 递归删除时受工作树内容影响。

### 3.3 恢复方法（留档用）

```bash
git submodule add https://github.com/cloudQuant/bt_api_<name>.git bt_api/bt_api_<name>
git -C bt_api/bt_api_<name> checkout <sha>          # 附录 A 中的 pin
git add .gitmodules bt_api/bt_api_<name>
```

## 4. 引用清理分层设计

### 4.1 分层

| 层 | 范围 | 处理策略 |
|----|------|----------|
| L1 仓库元数据 | `.gitmodules` | 删除段（第 3 节） |
| L2 代码与配置 | `conftest.py`、`pyrightconfig.json`、`scripts/**`、`_generate_docs.py` | 删除交易所相关项，保持语法与语义完整 |
| L3 活跃文档 | `bt_api/readme.md`、`docs/CODE_QUALITY.md`、`docs/exchanges/*`、`docs/source-tree-analysis.md` | 删除行/表行，修正统计口径 |
| L4 示例 | `examples/network_tests/**` | 专属文件整份删除；README/混合文件摘除条目 |
| L5 历史归档 | `docs/archive/**`、`docs/plans/**`、`docs/superpowers/**`、`docs/迭代计划/迭代01-02`、`docs/acceptance/2026-08-17-baseline-inventory.json` | 摘除引用行，保留其余历史内容 |

### 4.2 边界规则

- **不删整份历史归档**（除纯专属文件），避免破坏历史证据链。
- **不改归档结论**：摘除后不新增任何"保留/移除"结论性描述。
- **不改 `.gemini/`**：非交易所引用。
- **不改 `tests/`**：`tests/` 无硬编码交易所清单（`tests/test_repository_baseline.py` 读 `.gitmodules`），实测全仓扫描 `tests/` 无命中。
- **不改 `docs/data/exchange_support_matrix.json`**：抽象 tier，无枚举。
- **不改 `docs/AGENTS.md`**：活跃文档契约文件，无交易所枚举。
