## 1. 验收说明

- 验收分三层，证据形式各不相同：
  1. **离线验收**：单测/契约测试，不触网（假 transport、录制回放）；
  2. **真机验收**：真实站点/API 取数（akshare 站点、同花顺扶摇、各 provider 上游）；
  3. **真实场景验收**：全市场 10 年日线 + 复权因子的完整拉取演练（本迭代的核心业务场景）。
- 每项 AC 的证据格式：命令 + 输出摘录 + 结论（实施后回填 §9）。
- **许可合规（AC-10）是一票否决项**：任何 AGPL 源码污染或 akshare 运行时依赖都会导致本轮验收不通过，
  不接受"后续修复"。AC-10 单列于第 3 节（编号提前占用，功能项从 AC-11 续接）。

## 2. 功能验收

### AC-1 统一契约与数据模型

- 设计 §3.1 列出的模型全部存在，字段完整，可 `to_dataframe()` 且列名/dtype 固定。
- 时间语义：naive 输入按 UTC 解释、带时区输入转 UTC；与 `data_downloader._parse_time` 一致。
- 每条记录 `source` 字段被回填（可追溯来源）。

### AC-2 注册、能力与路由

- `bt_api.data_sources` entry point 可被发现；`api.list_data_sources()` 列出已安装源。
- `Capability` 覆盖声明可查询（`describe_data_source`）；`upstream-pending` 能力被明确标注。
- `source="auto"` 按 `data-routing.toml` 顺序选择；首选源失败时降级到备选，且降级链
  （源、失败原因）可查。
- `source="<name>"` 精确路由：源不可用（无 Key/未安装）时报明确错误，不静默换源。
- 能力不匹配（如向宏观源请求分钟线）→ `CapabilityNotSupportedError`。

### AC-3 `BtApi` 统一入口与向后兼容

- 设计 §3.5 的方法全部可用，返回标准化 DataFrame。
- `download_history_bars` 行为不变（既有 venue 测试全绿）。
- 异常统一为 `DataSourceError` 家族，携带 `source` 与 `attempts`。

### AC-4 请求治理

- 重试：幂等 GET 指数退避 + 抖动；非幂等不重试。
- 限流：按 host 令牌桶生效（可测：连续请求被节流）；429/403 触发退避与熔断标记。
- 失败分类：网络/超时/限流/反爬/上游错误各自可区分。
- 日志脱敏：不出现 API Key。

### AC-5 `bt_api_http` 全量搬运

- akshare 40 个子模块 + 5 个顶层模块**全部**在 `bt_api_data/packages/bt_api_http/` 内存在。
- **命名契约**：公开函数沿用 akshare 原名且不带 `akshare` 前缀——
  `bt_api_http.stock_zh_a_hist` 可用，包内不存在 `akshare` 命名空间。
- 全量 `import` 冒烟：每个模块可导入，公开函数可解析。
- 内置资源可用：`data/`、`file_fold/` 的资源在**干净安装**（非源码目录）下可读取。
- `verify_no_akshare.py` 全绿：包内无 `akshare` 运行时引用。
- 搬运差异报告无"未处理"项。

### AC-6 搬运保真对照

- P0 数据域（A 股日线/复权/财务/指数成分/期货日线）**逐接口**对照：
  列集合、dtypes、行数、主键排序一致；数值列抽样一致（浮点容忍 1e-6）。
- 冷门域：每个模块 ≥1 接口对照（可录制者）或结构检查（不可录制者）。
- 差异清单中的每一项都有明确解释（上游数据漂移/接口本身不稳定/已知缺陷），无未解释差异。
- 对照报告落档（`docs/iter-07-port-report.md`）。

### AC-7 `bt_api_fuyao` 全端点

- 设计 §5.3 端点分组逐组真机验证（Key 已有）：
  - 基础（检索/列表/日历）、A 股行情、除复权、财务报表、财务指标、指数列表与成分、估值/竞价/资金/特色
  - 期货（资料/持仓/仓单/基差/日程）、期权（资料/分时/日K）、基金（资料/持仓/业绩/净值/额度/指标）
- 错误码分支全覆盖（0/1001–1004/2001/2003/3001–3004/4001/5001–5003）。
- `1003` 历史窗口超限时自动分段，结果拼接正确。
- 文档标注"暂不可用"的能力：实现存在、能力声明标注 `upstream-pending`、路由不误选。
- Market Dumps：全市场 10 年日 K + 最近 10 交易日日 K + 复权因子 Parquet 下载并解析，
  行数/标的数与文件元信息一致。

### AC-8 自研 provider（32 个）

- `bt_api_data/packages/` 下 32 个 provider 包全部存在、可注册、`list_data_sources()` 可见。
- P0（12）与 P1（16）每源 ≥2 个能力真机取数（无 Key 的商业源验证"未配置时正确降级/报错"）。
- P2（4）真机抽样通过，README 说明结构特殊性并标注 experimental。
- 与上游官方输出对照通过（设计 §9 L3）。

### AC-9 接口对照表

- `docs/data-source-mapping.md` 覆盖 P0/P1 全部能力：OpenBB 调用 ↔ bt_api_py 调用。
- 对照表**不含任何 OpenBB 源码片段**（人工审查）+ CI 相似度扫描通过。

### AC-11 缓存、批量与续拉

- 缓存：同参数二次调用不发网络请求（假 transport 断言请求次数）。
- 不可变区间策略生效（历史区间长期命中；当日不缓存或短 TTL）。
- `fetch_many`：单标的失败不阻断；失败清单可导出；并发上限与限流联动。
- 续拉：中断后重跑只处理 pending 项（进度文件断言）。

### AC-12 上游同步机制

- `upstream.lock` 记录上游 commit 与逐文件 sha256。
- 模拟上游变更（本地副本改签名）→ `fetch_upstream --diff` 能报出该文件与函数签名差异。
- 同步流程文档齐全（diff→评估→重跑→对照→提交）；`manual_edits` 文件不被覆盖。

## 3. 许可合规验收（一票否决）

### AC-10 零 AGPL / akshare MIT 声明完整 / 运行时零上游依赖

| 检查项 | 判定方式 | 通过标准 |
|--------|---------|---------|
| 无 OpenBB 源码 | CI 相似度扫描（n-gram/行级）+ 人工审查 | 无超阈值文件；无源码片段/注释引用 |
| PR 声明留档 | 每个 provider PR 模板字段 | "无源码参照"声明齐全 |
| akshare MIT 声明 | 检查文件头 + `THIRD_PARTY_NOTICES.md` | 每个搬运文件有来源标注；NOTICES 含许可全文 + 仓库 URL + commit |
| 来源可追 | `upstream.lock` | 逐文件 sha256 与上游路径完整 |
| 运行时无 akshare | 干净环境 `python -c "import bt_api_http"`；`pip show akshare` 为空 | 导入成功且未安装 akshare |
| 运行时无 openbb | 同上 | 导入 `bt_api_data/packages/` 下全部 provider 包不依赖 openbb |
| 主包许可不变 | `LICENSE` 与打包元数据 | 仍为 MIT |

## 4. 数据质量验收

- 模型层：`Bar` 等模型对同一上游数据重复映射结果稳定（幂等）。
- 对照层：见 AC-6 / AC-7 / AC-8，容忍度在报告里显式声明。
- 口径一致性：时间（UTC/毫秒/交易所本地）、单位（手/股/元/万元）、复权（qfq/hfq/不复权）
  在模型注释与 README 中写明；跨源同一标的抽样比对（fuyao vs akshare）方向与量级一致，
  差异有解释（源口径不同）。

## 5. 性能与限流验收

| 项 | 指标 | 验收方式 |
|----|------|---------|
| 全市场 10 年日线 | 走 fuyao market-dumps 时 ≤ 分钟级（下载+解析） | 真实演练计时并记录 |
| 逐标的回退路径 | 不设硬指标，但不得触发源侧封禁 | 限流触发次数与失败率记录 |
| 缓存命中 | 重复任务网络请求数 ≈ 0 | 假 transport / 代理计数 |
| 并发默认值 | 不触发 429 的比例 ≥ 99%（P0 源抽样） | 真实演练统计 |
| 内存 | 批量任务内存不随标的数线性增长（分批释放） | 抽样 RSS 记录 |

## 6. 可靠性验收（断点续拉与失败重入）

- 批量任务中断（kill）后重跑：已完成项跳过、失败项重试、结果与中断前一致。
- 单源不可用时降级：首选源故障 → 自动换源 → 结果可用且降级链可查。
- 反爬/结构变化：失败被分类为"反爬/上游变化"而非静默返回空数据（空 DataFrame 必须有明确原因）。
- 同花顺限流（429/4001）注入：退避生效、任务不崩、后续请求恢复。

## 7. 真实场景验收（本迭代核心）

1. **全市场 10 年日线 + 复权因子**：优先 fuyao market-dumps，降级逐标的路由；
   产出成功率、失败清单、耗时；随机抽样 20 个标的与第二源交叉核对。
2. **指数成分股**：沪深300 等标准指数 + 同花顺指数，成分数量与权重和符合常识
   （权重合计 ≈ 100%），与第二源抽样一致。
3. **财务报表与指标**：随机 20 个标的，三大报表 + 五类指标字段完整、期间连续。
4. **期货日线与基本面**：主力合约日线 + 持仓/仓单/基差抽样可用。
5. **海外与宏观**：yfinance 美股与 FRED 宏观各抽样 5 个，与官方页面/CSV 对照。
