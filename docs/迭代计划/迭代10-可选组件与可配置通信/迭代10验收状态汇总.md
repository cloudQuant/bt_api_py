# 迭代10 验收状态汇总（2026-10-14）

本文件把[正式迭代计划](正式迭代计划.md)第10节的 68 个用例收敛为一张可核对的状态表。
**当前没有任何一个用例被标记为正式 PASS**：每个用例都要求计划中写明的完整证据，而
本迭代已完成的部分只覆盖其中的一部分条件。逐轮范围、命令与结果见
[开发与验收进度.md](开发与验收进度.md)；本文件只做状态归并与证据定位。

| 部分/本机进程 | 已有真实本机服务进程/真实传输证据，但仍缺该用例要求的其他条件 |
| 本机进程 | 该用例要求的本机进程链路已跑通 |
| 正式 PASS | 该用例要求的全部证据齐备（含真实账户、跨机或负载等）——**目前为空** |

## 真实进程测试发现的真实缺陷（均已修复并留回归）

1. Backtrader 适配器把每对象自增的框架订单引用写进 intent 标签，破坏同一 intent 的幂等（第21轮）。
2. 同一 intent 的第二个框架订单会重复记账，需由框架 replay 守卫拒绝（第22轮）。
3. AFI 导入隔离检查依赖测试顺序，同批次真实进程测试会先加载领域包（第19轮）。
4. AFI 订单视图不接受注册表包裹的回复信封（`{ok, code, result}`），真实链路一律判为畸形（第26轮）。
