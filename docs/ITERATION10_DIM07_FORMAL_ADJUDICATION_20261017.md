## 证据边界

R6 的数值应称为“准入调用授予/拒绝耗时”，不能称为独立队列驻留时间或真实 CTP 时延。R6 没有连接 provider、账户、ServiceHost，也未构造真实 HTTP 429；对应行为由上述本机合成 provider/SQLite 节点覆盖。测试 warning 原样保留，不影响节点 exit 0。Gateway 组件验收按 45 个唯一 selector 的 R1/R2 增量证据表述，不改写为一次 45/45。上述场景按 DIM07 原行合并裁定；未重跑已有 QA。
