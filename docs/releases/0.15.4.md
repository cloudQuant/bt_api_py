# 0.15.4 发布说明

发布日期：2026-09-21

`0.15.4` 是一次质量与发布链路维护版本。它不扩大交易所或实盘交易
支持声明；安装后的可用范围仍应以 `doctor` 输出和
[support-status policy](../operations/support-status-policy.md) 为准。

## 修复

- 质量债务门禁现在会将 Windows 的反斜杠路径规范化为仓库相对 POSIX
  路径，避免已检出的子仓库被误判为缺失。
- OKX 子仓库的 README 示例已按项目 Ruff 格式化规则整理，使子仓库
  格式债务保持在既定基线内。
- 迭代 07 的执行会话改进继续生效：POSIX 文件锁的类型边界更明确，
  并覆盖 Windows 上迁移回滚期间的锁定文件观察行为。

## 依赖源

本版本固定的交易所适配器提交均从对应仓库当前 `master` 衍生，并保留
迭代 07 的后续质量修复。固定提交而非浮动分支使构建、测试与发布可以
复现；升级某个适配器时需要先完成该适配器的验证，再更新此仓库的 gitlink。

## 升级

```bash
python -m pip install --upgrade bt_api_py==0.15.4
python -m bt_api_py.doctor --bundle core-reference --format json
```

`doctor` 成功只证明安装包元数据和诊断路径可用，不代表交易所连接、
账户凭据或实盘下单已获认证。
