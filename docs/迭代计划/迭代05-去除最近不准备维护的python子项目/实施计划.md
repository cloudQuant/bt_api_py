## 4. 回滚方案

- **单文件回滚**：`git checkout -- <file>`。
- **整批回滚**：`git reset --hard <本迭代开始前的 commit>` + `git clean -fd bt_api/`，随后 `git submodule update --init --recursive` 恢复 submodule 工作树。
- **精确恢复单个被删 submodule**：按 `研发设计文档.md` 3.3 的 `git submodule add` + `checkout <sha>` 步骤。
