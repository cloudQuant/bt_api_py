# LOAD01 shared market ZMQ context round — 2026-10-17

This round shares one process-local ZMQ context among the twenty market subscribers created by one `ZmqMarketTransportFactory`. Every subscriber still owns its own topic-specific SUB socket, receiver and close lease; the existing socket HWM, maximum message size, wire validation and message queues are unchanged. The factory, pool, lease and subscriber reject use from a different process before acquiring inherited locks or touching sockets, with a second PID check inside the owned lock. Pooled startup cleanup retains the subscriber/context/lease when socket cleanup fails so the owner can retry `close()`.
