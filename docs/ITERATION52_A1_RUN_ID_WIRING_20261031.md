# 迭代 52 A1：只读会话运行标识接线

日期：2026-10-31。范围：`bt_api_runtime` V2 只读源码与模拟集成；仓库既有 `dev` 工作区。

## 变更

运行标识由调用方提供，在访问 SDK 或传输层之前校验格式并传给 factory。V2 factory 将同一个 `run_id` 传入 SDK runtime，检查 runtime 和账户、行情注册作用域；公开行情 stream scope 保持不含运行标识。预检检查 SDK binding view 方法的实际调用签名，不兼容时在 I/O 前拒绝。V1 维持原有调用形态。

`run_id` 只是关联标识，不证明服务端唯一性、读取许可或授权。自定义 factory 的 preflight 是声明，并不证明其实现正确传递标识。注册后的失败清理可能仍处于远端状态未知；此轮不声称解决该问题。SDK 直接构造器的空 ID 回退行为未修改。
